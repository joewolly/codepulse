# CodePulse 0.9.0

## Manual upgrade required

Manual download required for this upgrade. Download and install CodePulse 0.9.0
from this GitHub Release, replacing the older app in Applications.

Automatic updates resume after installing 0.9.0.

This fork release starts a new Sparkle signing-key line after the prior private
key could not be recovered. The historical `v0.8.0` release and tag are
unchanged.

## Included hardening

- Production signing is isolated in the protected `production-signing`
  environment with a 30-minute solo-maintainer wait timer.
- Release preflight uses a disposable signing key and does not access the
  production signing secret.
- Git metadata capture, usage records, and integration receipt handling have
  stronger execution, numeric, and storage bounds.
- Recovery backup disclosure and per-integration deletion behavior are aligned
  with the data the app actually stores.
