# CodePulse 0.9.2

## Settings stability and testability

Manual download required for this upgrade. Download and install CodePulse 0.9.2
from this GitHub Release, replacing the previous app in Applications.

Automatic updates resume after installing 0.9.2.

## Included updates

- Refactored **Settings → Integrations** into stable semantic sections:
  - Lifecycle Tracking
  - Token Usage
  - Cost Display
  - Agent Timing
- Fixed dynamic row identity collisions by using section-scoped IDs for lifecycle,
  token-usage, and cost controls.
- Added stable accessibility identifiers for verification, including cost picker IDs
  for each integration (for example `cost-display-codex`).
- Added unit-test coverage for section row counts and identity stability to prevent
  duplicated/misaligned cost and token controls from regressing in future changes.
- Re-validated full package validation and confirmed pricing catalog continuity in
  both staged app and DMG outputs.
