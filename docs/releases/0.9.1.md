# CodePulse 0.9.1

## Startup hotfix

Manual download required for this upgrade. Download and install CodePulse 0.9.1
from this GitHub Release, replacing the earlier app in Applications.

Automatic updates resume after installing 0.9.1.

This hotfix restores the bundled pricing catalog required during app startup.
Version 0.9.0 omitted that resource from its DMG, causing the app to quit at
launch. The packaging workflow now verifies the catalog in both the staged app
and mounted DMG; the release candidate was also built, signed ad-hoc, and
launched locally before publication.
